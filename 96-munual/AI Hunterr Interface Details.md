### 1. RS485 or TTL (UART7)
	Pin define from left to right: 

| **TTL**   | **VCC** | **RX** | **TX** | **GND** |
| --------- | ------- | ------ | ------ | ------- |
| **RS485** | **VCC** | **A**  | **B**  | **GND** |
> default VCC is 5V, mode is RS485

![](AI%20Hunterr%20Interface%20Details-1.png)  



### 2. RS485(UART4)
	Pin define from left to right: 

| **GND** | **TX** | **RX** | **VCC** |
| ------- | ------ | ------ | ------- |
| **GND** | **B**  | **A**  | **VCC** |
> default VCC is 5V, mode is RS485
